# Iron Pulse - Gym Management System 🏋️‍♂️

A modern, responsive landing page for a gym management system built using **Python (Flask)**, **HTML5**, and **CSS3**.

## 🚀 Features
- **Home Page**: High-impact hero section with a call to action.
- **About Us**: Information about gym facilities and expert coaching.
- **Membership Plans**: Tiered pricing tables (Basic, Pro, Elite).
- **Responsive Design**: Works on desktop, tablets, and mobile phones.
- **Flask Backend**: Organized folder structure for scalability.
